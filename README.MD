# Qirab™ Travel Target Holder for the QTC50

The Qirab™ Travel Target Holder (QTT) is an open-source design for holding object level targets, such as the [Image Science Associated Golden Thread object level target](https://www.imagescienceassociates.com/object-level-targets.html), to be used with the [Qirab™ Travel Digitisation Cradle (QTC)](https://qirab.org/en/docs/hardware/traveldigitisationcradle/) and the [Qirab™ Digitization Workflow](https://qirab.org/en/docs/resources/manuscriptdigitsationworkflow/).

The QTT allows precise manual height adjustment with greater than 0.5mm accuracy utilizing a common T8x8 lead screw manual mechanism. The QTT is a derivative of the <a href="https://github.com/Qirab/QirabTargetHolder">Qirab Target Holder</a>.
